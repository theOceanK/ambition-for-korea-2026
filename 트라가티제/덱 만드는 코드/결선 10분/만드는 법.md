# 트라가티제 결선 10분

- 양식: 팀 Drive `1 대회 당일/피치덱/템플릿` 의 「결선 10분 B 네이비 신뢰」(Google Slides → PPTX 로 받음 · `템플릿\`)
- 원천: 제출 2장(바탕화면 `트라가티제_2page.pdf`, 16:51) · 기획서 Google 문서(`원천_기획서.txt`, 199행부터 트라가티제) · 요금 개편 `..\트라가티제 요금\6절 수익 구조 새 판.html`(16시, 기획서 6절보다 우선)
- 결과: `트라가티제_결선_10분.pptx` · `트라가티제_결선_10분.pdf` (7쪽 · 쪽마다 발표 대본이 발표자 노트에)

## 다시 뽑기

```
..\트라가티제 제출 2장\.venv\Scripts\python.exe -I -X utf8 build_final.py 템플릿\B_네이비신뢰.pptx 트라가티제_결선_10분.pptx
pwsh -File "..\트라가티제 제출 2장\to_pdf.ps1" -In 트라가티제_결선_10분.pptx -Out 트라가티제_결선_10분.pdf
```

- 글 내용은 `build_final.py` 맨 위 TEXT · RUNS · SIZE · NOTES. 「|」 = 줄바꿈.
- 뽑을 때 줄마다 글자 폭을 재서 칸 폭의 90% 를 넘는 줄을 찍는다. 6쪽 팀 경력 3줄은 템플릿 원래 글이라 두 줄로 접히는 게 정상.
- Google Slides 에서 고치려면 PPTX 를 Drive 에 올리고 Google Slides 로 연다.
