# Ambition for Korea 2026 해커톤 기획 기록

- 팀 **트라가티제** 팀장, 발표 담당
- 36팀 중 **본선 8팀** 진출

## AI를 어떻게 썼나

- 도구: Claude Code(Anthropic). 진행 세션 하나가 일을 단계로 나눠 서브에이전트에게 맡기고, 결과를 모아 검토를 다시 맡겼습니다.
- 사람이 정한 것: 아이디어의 뿌리, 서비스 흐름, 이름, 채택 여부. 지시서 맨 앞 「사용자 지시 원문」이 그것입니다.
- AI가 한 것: 조사, 기획서 초안(린 캔버스), 검토, 말투 다듬기, 카드뉴스 피치덱, 숫자 대조.
- 흐름(톡2북킹 기준): `00_공통지시.md`(모든 에이전트가 먼저 읽는 규칙) → 기초 조사 → 기획서 초안 → 검토 · 고침 → 아나운서 말투로 다듬기 → 2장 카드뉴스 → 덱 검토 → 올리기. 단계마다 지시서 파일이 하나씩 있습니다(`02_기획서_지시.md` …).
- 문서 속 [근거] · [제 판단] · [제 해석] 표지는 AI가 출처 있는 사실과 자기 해석을 가르려고 붙인 것입니다.

## 공개하며 바꾼 것

- 팀원이 쓴 문서, 팀 대화 기록과 회의 녹음, 대회 발표자료 틀, 웹에서 받은 조사 원자료는 넣지 않았습니다. 앵콜 기획서에는 오전 회의에서 나온 말 몇 줄이 이름 없이 인용돼 있습니다.
- 다른 대회 우승작(챗2캐쉬) 출품 글은 원문 인용을 빼고 출처 링크만 남겼습니다.
- 문서에 적힌 내 컴퓨터 경로는 「(대회 전 준비 자료)」, 「(임시 폴더)」 같은 말로 바꿨습니다. 그 경로의 파일은 이 저장소에 없습니다.
- 카드뉴스 HTML은 대회 바닥글 그림이 빠져 있습니다. 완성된 모습은 같은 이름의 PDF로 보세요.
