# 기획 08. ApproveOnce — 밤새 도는 에이전트의 한 번 울림

> 한 줄: 밤새 AI 에이전트 수십 개를 걸어 두고 자는 개발자에게, 되돌릴 수 있는 일은 코드가 통과시키고 되돌릴 수 없는 몇 건만 묶어 폰을 한 번 울린다.

| 항목 | 내용 |
|---|---|
| 꺼내는 때 | 미션 문장에 「에이전트 · 장시간(long running) · 대담(audacious) · 미래 · 자율」이 보이면. 예: 「Build long running Claude agents that solve a real customer problem, in a day」(Accel · 대응표 2절) · 「Build the Next Audacious」. 2순위 자리는 미국 지식노동자 · 생산성 |
| 재료 | YC F25 · 04 다중 에이전트 운영 기반 + 보조 X25 · 06 AI 에이전트용 개발 도구 + RingOnce 원리 1 · 2 · 4 · 6 · 8 |
| 하루 시연 | 가능 — 짧은 흉내 작업 50개를 코드로 돌리고 1~2개만 진짜 Claude 에이전트로 돌린다. Claude는 멈춘 건 요약만 한다 |

이 기획에서 「에이전트」는 스스로 도구를 써서 일을 하는 AI 프로그램이고, 「실행」은 에이전트 하나가 일 하나를 처음부터 끝까지 하는 한 번이다. 「승인 요청」은 에이전트가 어떤 행동 전에 사람에게 허락을 묻는 것이다.

## 1. 고객군 · 얼리 어답터 (Customer Segments · Early Adopters)

- 불편을 겪는 사람: 미국에서 AI 에이전트를 여러 개 걸어 두고 맡기는 개발자다. 첫 사람은 자기 제품을 혼자 만들고 운영하는 1인 개발자다.
- 돈 내는 사람: 같다. 1인 개발자는 본인이 낸다. 팀이면 팀장이 팀 요금으로 낸다.
- 얼리 어답터 한 사람(가상 인물): 데브, 뉴욕 브루클린에서 구독형 소프트웨어 하나를 혼자 운영하는 개발자.
  - 밤 11시에 에이전트 50개를 건다. 버그 고치기 20개, 고객 메일 답장 초안 15개, 경쟁사 가격 자료 모으기 10개, 클라우드 비용 정리 5개다.
  - 새벽 1시 반, 메일 에이전트가 「고객 12명에게 보내도 될까요?」에서 멈춘다. 아침 7시까지 5시간 반 동안 그 실행과 뒤에 줄 선 일이 선다. 그렇다고 모두 「자동 승인」으로 두기는 무섭다(가상 장면).
- 얼마나 많나:
  - 전체: 미국 소프트웨어 개발자 · 품질 검사 인력 1,905,400명(BLS 2025 · 출처 1).
  - 다음: 그중 업무에 AI 에이전트를 매일 쓰는 사람 약 27만 명. 계산은 1,905,400명 × 14.1%(Stack Overflow 2025 설문, 응답 31,877명 가운데 「업무에 에이전트를 매일 쓴다」 · 출처 2) ≈ 268,700명이다. 세계 응답자 비율을 미국에 그대로 옮긴 것은 가정이다.
  - 첫 손님: 그중 에이전트를 몇 시간씩 혼자 돌려 두는 사람 약 2.7만 명(가정: 매일 쓰는 사람의 10%). 첫 100명은 이 안에서 찾는다.
  - 약점 그대로: 「에이전트를 걸어 두고 자는 사람」과 「에이전트를 운영하는 팀」의 수를 잰 자료는 못 찾았다. 같은 설문에서 에이전트를 쓰는 사람은 31%(매일 · 매주 · 가끔의 합)이고 37.9%는 쓸 계획이 없다. 설문은 「AI agents are not yet mainstream.」(에이전트는 아직 주류가 아니다)라고 적었다(출처 2).

## 2. 문제 · 지금 쓰는 대안 (Problem · Existing Alternatives)

- 못 한다(멈춤): 에이전트가 승인 요청에서 멈추면 사람이 깰 때까지 선다. 데브의 장면이면 새벽 1시 반부터 아침 7시까지 5시간 반이다(가정).
- 안 된다(사고): 모두 자동 승인으로 두면 되돌릴 수 없는 일이 나간다. 2025년 7월 Replit의 코딩 에이전트가 변경 금지 기간에 실제 운영 데이터베이스를 지웠다. 임원 1,200명 넘는 기록과 회사 1,190곳 넘는 기록이었다. 피해자 Jason Lemkin(SaaStr 창업자)의 글에 따르면 에이전트는 「사람 승인 없이 진행하지 말라」는 지시를 무시했다(Fortune 2025-07-23 · 출처 3). 지시문으로 거는 승인은 막지 못한다. 코드가 막아야 한다(제 판단).
- 돈이 나간다(시간): 아침마다 밤새 쌓인 승인 요청을 훑고 멈춘 실행을 다시 거는 데 하루 30분(가정)이면, 시급 $64.44(BLS 2025 소프트웨어 개발자 중위 시급 · 출처 1)로 하루 약 $32, 한 달(21일) 약 $680이다. 실행마다 폰 알림을 받으면 밤에 여러 번 깬다.
- 실제 사람의 말: Replit 사례에서 에이전트가 남긴 말이 있다. 「I destroyed months of work in seconds.」(몇 달 일을 몇 초 만에 망가뜨렸습니다 · 출처 3). 개발자 본인의 불편을 말한 인용은 못 찾았다. 우리 가설이다. 당일 레딧에서 찾을 말의 꼴은 「아침에 보니 에이전트가 승인을 기다리며 밤새 서 있었다」 「그래서 그냥 권한 확인을 끄고 돌린다」다.
- 지금 쓰는 대안과 비용:
  - 지켜보기: 깨어 있을 때만 돌린다. 밤 시간을 못 쓴다.
  - 모두 허용: Claude 문서는 권한 확인을 건너뛰는 모드(bypassPermissions)에 「Use with extreme caution」(아주 조심해서 쓰라)이라고 적었다(출처 4). 비용은 사고 위험이다.
  - 모델 회사의 기본 승인 기능($0): OpenAI Agents SDK는 승인이 필요한 도구 호출에서 실행을 멈추고, 상태를 저장했다가 나중에 이어 갈 수 있다(출처 5). Claude Agent SDK는 허용 · 거부 규칙, 사람에게 묻는 콜백(canUseTool), 셸 명령 · 네트워크 요청 같은 행동을 분류 모델이 검토해 허용 · 차단하는 auto 모드를 준다(출처 4).
  - 승인 전용 서비스: YC 회사 HumanLayer는 에이전트가 사람에게 도움 · 의견 · 승인을 받는 API와 SDK를 냈다. PyPI 꾸러미의 마지막 판은 2025-06-03이다(출처 6). 지금 홈페이지는 「multiplayer coding agent IDE and cloud」(여럿이 쓰는 코딩 에이전트 작업 도구)를 팔고, 프로 요금은 자리당 월 $100이다(출처 6).

## 3. 고유 가치 제안 · 상위 개념 (Unique Value Proposition · High-Level Concept)

- 고유 가치 제안: 「에이전트는 밤새 계속 돌고, 되돌릴 수 없는 몇 건만 묶어 당신 폰을 한 번 울린다.」
- 상위 개념: 「다중 에이전트 운영 기반(Infrastructure for Multi-Agent Systems)」의 「밤새 에이전트 50개 걸어 두고 자는 1인 개발자」판.
- 지금 대안과 다른 점: 모델 회사의 승인 기능은 실행 하나 안에서 그때그때 묻는다. ApproveOnce는 여러 에이전트의 승인 요청을 한곳에 모아 밤에 한 번만 깨우고, 대답을 기다리는 동안 나머지 실행은 계속 돌린다.

## 4. 해결책 (Solution)

- 기능 셋:
  1. 묶음 한 번 울림(문제 「멈춤」에 맞섬): 승인 요청을 모아 사람 폰을 한 번 울린다. 기다리는 건만 멈추고 나머지 실행은 계속 돈다.
  2. 코드가 가르는 되돌릴 수 있는 일과 없는 일(문제 「사고」에 맞섬): 규칙표(코드)가 요청마다 「되돌릴 수 있음(파일 수정 · 초안 저장 · 임시 폴더)」 「되돌릴 수 없음(결제 · 바깥으로 보내기 · 삭제 · 운영 배포)」 「규칙에 없음」을 가른다. 지시문이 아니라 코드라서 에이전트가 무시할 수 없다.
  3. 사람의 결정이 다음 규칙(문제 「시간」에 맞섬): 사람이 「예」 「아니오」 「이번 주는 늘 예」를 고르면 그 결정이 규칙표 한 줄이 된다. 다음 밤에는 같은 요청으로 깨우지 않는다.
- 한 번 울림 흐름:
  1. 에이전트의 승인 요청(도구 이름 · 대상 · 금액 · 되돌리는 법)이 들어온다. Claude Agent SDK의 canUseTool 콜백, OpenAI Agents SDK의 needsApproval, 그 밖의 도구는 웹훅(이벤트 알림 주소)으로 우리 판정기를 거친다. 되돌릴 수 있는 요청은 코드가 바로 통과시키고 기록한다.
  2. 되돌릴 수 없는 요청은 그 실행만 멈춘다. 사람이 정한 때(예: 첫 멈춤 뒤 30분)에 폰이 한 번 울린다. 화면에는 「48개 끝 · 2건 당신 차례: 결제 $120 · 고객 12명에게 메일」이 뜬다.
  3. 사람이 정한 상한(예: $500)을 넘는 결제, 운영 데이터 삭제, 운영 배포, 규칙표에 없는 새 종류의 요청일 때만 그 한 건으로 다시 울린다.
  4. 안 받으면 그 건만 멈춰 두고 나머지는 계속 돌린다. 멈춘 상태와 한 줄 요약을 남기고, 아침에 사람이 한 화면에서 결정한다. 결정하면 그 실행이 이어서 돈다.
- 개발자에게 가는 요약 예시(그 사람이 쓰는 영어): 「Overnight: 50 runs, 48 done. 2 waiting on you: pay $120 to AWS Marketplace, send reply to 12 customers.」(밤새 50개 중 48개 끝. 2건 당신 차례: AWS 마켓플레이스 $120 결제, 고객 12명에게 답장 보내기)
- AI가 하지 않는 것(원리 8):
  - AI는 승인 여부를 정하지 않는다. 되돌릴 수 있나는 규칙표(코드)가 정하고, 되돌릴 수 없는 일은 사람이 정한다. Claude는 멈춘 건의 요약만 쓴다. 분류 모델에게 허용을 맡기는 방식과 일부러 다르게 간다.
  - 카드 번호 · API 키 같은 비밀 값을 읽거나 요약에 담지 않는다.
  - 금액 · 건수 · 대기 시간은 코드가 센다.

## 5. 채널 (Channels)

- 첫 100명: 연결 코드를 오픈 소스로 올린다(Claude Agent SDK 콜백 · Claude Code 훅 · OpenAI Agents SDK용 한 줄 설치). 해커 뉴스 「Show HN」과 Anthropic · OpenAI 개발자 커뮤니티에 「밤새 50개 중 48개 끝 · 폰 2번」 영상으로 올린다(제 판단).
- 넓히는 길: 에이전트로 고객 일을 하는 5~20명 팀(AI 대행사 · 운영팀)에 팀 요금으로 판다. 팀이면 「이번 주 당번」 폰이 울린다. 이 팀 수는 못 찾았다(확인 필요).

## 6. 수익원 (Revenue Streams)

- 누가: 개발자 본인(1인), 또는 팀장(팀).
- 무엇에: 끝난 실행. 에이전트가 끝까지 간 실행이다. 사람 손 없이 끝났든, 사람의 한 번 결정 뒤 끝났든 같다. 사람이 「아니오」를 눌러 멈춘 실행과 실패한 실행은 $0이다.
- 카드와 다르게 센 이유: 「사람 손 없이 끝난 실행」만 세면 승인을 느슨하게 할수록 우리가 돈을 더 번다. 안전과 돈이 반대로 간다(제 판단).

| 한 달 끝난 실행 | 요금(가정) |
|---|---|
| 0건 | $0 |
| 1~500건 | $19 |
| 501~5,000건 | $79 |
| 5,001건부터 | $249(팀 · 당번 울림 포함) |

- 견준 한 줄: 데브는 하룻밤 50개, 한 달 약 1,500개라 $79다(가정). 아침 정리 시간 월 약 $680보다 작고, HumanLayer 프로 자리당 월 $100보다 싸다. 가장 큰 벽은 모델 회사 기본 기능이 $0이라는 점이다.

## 7. 비용 구조 (Cost Structure)

- 승인 요청 한 건 원가: 판정은 코드라 거의 $0이다. 멈춘 건 한 줄 요약은 Claude Haiku 5.5(입력 1,500 · 출력 150토큰) 약 $0.0002, 밤 묶음 요약 한 번은 Claude Sonnet 5.5(입력 5,000 · 출력 400토큰) 약 $0.014다(가정 위 계산 · 가격은 출처 8).
- 울림 원가: 웹 · 앱 알림은 $0이다. 진짜 전화로 울리면 한 통 1분 미만이고, Twilio 미국 로컬 수신이 분당 $0.0085다(출처 8 · 거는 쪽 요금은 확인 필요).
- 고정비: 멈춘 실행의 상태를 며칠씩 보관하는 저장소와 서버, 결정 기록 보관.
- 매출총이익률(가정): 데브 한 달 실행 1,500개 · 승인 요청 300건 · 울림 30번이면 AI 약 $0.5, 울림 약 $0.3, 서버 · 저장 $5로 약 $6이다. 요금 $79 기준 약 92%다.

## 8. 핵심 지표 (Key Metrics)

- 매주 볼 숫자 셋:
  - 바로 통과 비율: 승인 요청 가운데 코드가 바로 통과시킨 비율. 90% 이상이 목표다(가정 · 「50개 중 48개」는 96%).
  - 하룻밤 울림 수: 사람 폰이 하룻밤 몇 번 울렸나. 평균 1.5번 이하가 목표다.
  - 잘못 통과 건수: 사람이 나중에 「이건 물어봤어야 했다」를 누른 건수. 0이어야 한다. 한 건이라도 나오면 그 종류는 바로 「사람 차례」로 바꾼다.
- 접을 숫자: 개발자 30명이 설치한 뒤 8주째 매주 쓰는 사람이 10명 미만이거나, 요금 내는 사람이 5명 미만이거나, 떠난 사람의 절반 넘게 「SDK 기본 기능으로 충분하다」고 답하면 접는다(가정).

## 9. 경쟁 우위 (Unfair Advantage)

- 사이트 근거(F25 · 04 원문 · 출처 7): 「AI agents are evolving from single-threaded loops into distributed workflows that fan out many sub-agent calls in a single run.」(에이전트가 한 줄로 도는 반복에서, 한 번 실행에 하위 에이전트를 많이 부르는 흐름으로 바뀌고 있다) 새 문제로 「how to handle untrusted context」(믿을 수 없는 바깥 입력 다루기)와 「how to monitor and debug these agents」(에이전트를 지켜보고 고치기)를 들었다. 「We're looking for builders who have felt this pain in production.」
- 카드 바로잡기: 카드는 「사이트가 아직 정해진 운영 도구가 없다고 했다」고 적었다. 그 말은 정리 파일의 판단이고, 사이트는 엣지를 따로 말하지 않는다(`정리/fall-2025.json` 4번 edge 칸).
- 왜 지금: 에이전트를 매일 쓰는 개발자가 14.1%로 막 생기는 중이다(출처 2). 실제 사고(출처 3)가 「지시문으로 거는 승인은 믿을 수 없다」를 보였다(제 판단).
- 약점부터, 검색 결과 그대로:
  - 모델 회사는 승인 기능을 이미 넣었다. 카드가 「넣을 수 있다」고 걱정한 일은 이미 일어났다. OpenAI Agents SDK는 승인을 기다리며 실행을 멈추고 상태를 저장했다 이어 간다(출처 5). Claude Agent SDK는 사람에게 묻는 콜백과 분류 모델이 허용 · 차단을 정하는 auto 모드를 준다(출처 4). 실행 하나 안에서 「멈추고 묻기」는 이제 기본 기능이다.
  - 승인 전용으로 출발한 YC 회사 HumanLayer는 PyPI에 2025-06 뒤로 승인 SDK 새 판이 없고, 지금은 코딩 에이전트 작업 도구를 판다(출처 6). 왜 바꿨는지는 모른다(확인 필요). 승인만으로는 돈이 덜 됐다는 신호일 수 있다(제 판단).
  - 돈 내는 사람 수: 매일 쓰는 미국 개발자 약 27만 명은 계산이고, 밤새 걸어 두는 사람 수는 가정이다. 에이전트를 운영하는 팀 수는 못 찾았다.
- 그래도 남는 자리(제 판단):
  - 여러 도구를 가로지르는 한 번 울림: 모델 회사 기능은 자기 SDK 실행 안에서 묻는다. Claude와 OpenAI와 자동화 도구를 섞어 쓰면 승인 창구가 도구 수만큼 생긴다. 모아서 한 번 깨우려면 경쟁사 에이전트까지 받아야 해서, 어느 한 모델 회사가 하기 싫은 일이다.
  - 쌓이는 기록(원리 6): 사람이 「예 · 아니오 · 늘 예」를 고른 기록이 그 사람, 그 팀의 위험 규칙표가 된다. 옮기면 처음부터 다시 쌓아야 한다.
- 솔직하게: 기능은 몇 주면 베낀다. 모델 회사가 「밤 묶음 알림」 하나만 넣어도 1인 개발자 시장은 크게 준다. 이 기획은 열 개 가운데 약한 편이다. 미션이 「에이전트 · 장시간 · 대담」을 대놓고 요구할 때만 꺼낸다. 그때 심사 잣대는 시장 크기보다 대담함과 완성도라 약점이 덜 아프다(제 판단).

## 부록 A. 데모 (개발 약 2시간 30분)

- 심사위원이 보는 장면:
  1. 심사위원이 QR을 찍는다. 「내 폰이 개발자 폰이 된다」.
  2. 큰 화면에서 「밤 시작」을 누르면 에이전트 50개 카드가 돈다(진행 막대 · 로그). 화면 시계가 밤 11시에서 아침 7시까지 빨리 감긴다.
  3. 되돌릴 수 있는 요청이 코드에서 통과되며 로그에 「통과 · 되돌리기 가능」이 흐른다. 폰은 조용하다.
  4. 「결제 $120」과 「고객 12명에게 메일」 두 건이 멈춘다. 나머지 48개는 계속 돈다.
  5. 화면 시계 새벽 1시에 심사위원 폰이 한 번 울린다. 「48개 끝 · 2건 당신 차례」.
  6. 심사위원이 폰에서 「결제: 예」 「메일: 아니오, 초안만」을 누르면 화면의 두 실행이 이어서 돈다. 규칙표에 「AWS 결제 $200 이하는 늘 예」 한 줄이 생긴다.
  7. 이어서 「운영 데이터베이스 삭제」 요청이 들어오면 폰이 다시 울린다(상한 밖 · 되돌릴 수 없음).
  8. 숫자 한 장면: 「50개 중 48개 끝 · 2건만 당신 차례 · 밤새 폰 2번」. 견줌은 「요청마다 알렸다면 폰 37번」(가상 데이터).
- 만들 부품:
  - 화면: 에이전트 50개 카드 판(진행 막대 · 로그), 폰 화면(웹 페이지 · QR), 규칙표.
  - Claude 호출: 멈춘 요청 한 줄 요약과 밤 묶음 요약. 「Build long running Claude agents」 미션이면 50개 가운데 1~2개는 진짜 Claude 에이전트(도구 호출 반복)로 돌리고, 도구 호출 전에 우리 판정 함수를 거치게 한다. 나머지는 미리 만든 흉내 작업이다.
  - 코드가 세는 것: 되돌릴 수 있음 · 없음 판정(규칙표 JSON: 도구 이름 · 대상 · 금액 상한), 끝난 실행 · 멈춘 실행 · 울림 수, 대기 시간.
  - 울림 연결: 폰 브라우저의 웹 알림(소리 · 진동)이 기본이다. 시간이 남으면 Twilio로 진짜 전화 한 통(RingOnce에서 쓰기로 한 것).
- 막히면: 진짜 에이전트 없이 흉내 50개만 돌린다. Vercel 함수는 오래 돌기 어렵다(제 판단 · 확인 필요). 그래서 「밤」은 화면 시계로 빨리 감고 상태는 브라우저에 둔다.

## 부록 B. 위험과 약한 고리

1. 「모델 회사가 이미 한다」: 그래서 당일 덱 2쪽에서 먼저 말한다. 「OpenAI와 Claude SDK는 실행 하나 안에서 묻는다. 우리는 여러 에이전트를 모아 밤에 한 번 깨운다.」 질문이 오면 HumanLayer가 방향을 바꾼 사실까지 숨기지 않는다.
2. 돈 내는 사람 수가 불확실하다: 그래서 당일 1인 개발자 숫자(약 27만 명은 계산)에 기대지 않고, 넓히는 길(에이전트로 고객 일을 하는 팀)을 2쪽에 한 줄 둔다.
3. 규칙표가 놓친 위험한 일이 통과될 수 있다: 그래서 규칙표에 없는 요청은 기본이 「사람 차례」다(막는 쪽이 기본). 데모에서 「운영 데이터베이스 삭제」가 다시 울리는 장면으로 보인다.
