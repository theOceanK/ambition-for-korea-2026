# 05. 카드뉴스를 Google Slides 로 올리기 지시

카드뉴스 HTML(PDF 와 같은 화면)에서 잰 모양을 Google Slides 요청으로 바꿔 둔 파일이 있다. 너는 그 요청을 그대로 Google Slides 에 보내고, 결과를 그림으로 받아 저장한다. 요청 내용을 고치거나 새로 만들지 않는다.

## 쓰는 도구

- `mcp__claude_ai_Google_Drive__create_file`: 새 프레젠테이션 만들기(`contentMimeType` = `application/vnd.google-apps.presentation`, `parentId` = 진행자가 준 폴더 ID, `title` = 진행자가 준 이름).
- `mcp__claude_ai_Google_Slides__read_presentation`: `fields` = `["slides.objectId"]` 로 기본 슬라이드 ID 를 읽는다(보통 `p`).
- `mcp__claude_ai_Google_Slides__update_presentation`: 요청 묶음 보내기.
- `mcp__claude_ai_Google_Slides__read_slide_page_thumbnail`: `pageId` = `slide1` · `slide2`, `thumbnailProperties` = `{"thumbnailSize": "LARGE"}`. 돌려받은 그림 주소(contentUrl)를 curl 로 받아 저장한다.
- 이 도구들은 지연 도구다. 처음에 ToolSearch 로 `select:mcp__claude_ai_Google_Drive__create_file,mcp__claude_ai_Google_Slides__read_presentation,mcp__claude_ai_Google_Slides__update_presentation,mcp__claude_ai_Google_Slides__read_slide_page_thumbnail` 를 불러온다.

## 순서 (덱 하나마다)

1. 프레젠테이션을 만들고(진행자가 이미 만들어 ID 를 줬으면 건너뜀) 기본 슬라이드 ID 를 읽는다.
2. 요청 묶음을 꺼낸다:
   `python -I -X utf8 "RingOnce YC 결합 기획\카드뉴스\print_chunk.py" <요청 파일 이름> <묶음 번호> <기본 슬라이드 ID>`
   묶음 번호는 0부터. 첫 줄에 묶음 수가 나온다.
3. 출력된 JSON 배열을 **글자 하나 바꾸지 않고** `update_presentation` 의 `requests` 로 보낸다. 묶음마다 한 번씩, 0번부터 차례로.
   - 오류가 나면 그 묶음은 통째로 반영되지 않는다(원자적). 오류 문구를 그대로 보고하고 다음 덱으로 넘어간다. 요청을 고쳐 보내지 않는다.
4. 그림을 받는다: 두 장의 썸네일 주소를 curl 로 받아
   `(임시 폴더)\slides_png\<요청 파일 이름에서 .json 뺀 것>_<1|2>.png` 에 저장한다.
5. 저장한 그림을 Read 로 열어 본다. 글이 상자를 넘치거나, 줄이 이상하게 꺾이거나, 글자가 겹치거나, 로고 띠가 없거나, 빈 슬라이드가 있으면 적는다.

## 보고

덱마다 한 줄: 프레젠테이션 ID · 보기 주소 · 묶음 성공 수/전체 · 그림 파일 경로 · 눈에 띈 문제. 고치지는 않는다(진행자가 고친다).
