# 06. 마크다운 파일을 Google 문서로 올리기 지시

로컬 마크다운 파일을 Google Drive 의 지정 폴더에 Google 문서로 올린다. 내용은 한 글자도 바꾸지 않는다.

## 도구

- `mcp__claude_ai_Google_Drive__create_file` (지연 도구 · 처음에 ToolSearch `select:mcp__claude_ai_Google_Drive__create_file` 로 불러온다)
  - `title` = 진행자가 준 문서 이름
  - `parentId` = 진행자가 준 폴더 ID
  - `contentMimeType` = `text/markdown` (Google 문서로 바뀌며 제목 · 표 · 목록 서식이 살아난다)
  - `textContent` = 파일 내용 **전체 그대로**

## 순서 (파일마다)

1. Read 로 파일을 처음부터 끝까지 읽는다(길면 나눠 읽되 빠짐없이).
2. 읽은 내용을 줄 번호 없이 **그대로** `textContent` 에 넣어 올린다. 줄이거나 요약하거나 다듬지 않는다. 표 · 코드 블록 · 인용 표시도 그대로.
   - **예외 하나: 모든 `~` 를 `\~` 로 바꿔 보낸다**(코드 블록 안은 그대로). Google 변환기가 한 문단 · 표 칸 안의 `~` 두 개를 취소선으로 읽어 `~` 를 지우기 때문이다(10-24 실측). `\~` 로 보내면 문서에는 `~` 가 그대로 남는다(진행자 시험). 로컬 파일은 고치지 않는다.
3. 결과의 문서 ID 와 주소를 적는다.

## 규칙

- 지정된 파일만 올린다. 로컬 파일은 고치지 않는다. 같은 이름 문서를 두 번 만들지 않는다(실패하면 오류 문구를 적고 한 번만 다시 시도).
- 끝나면 진행자에게 표로 보고: 파일 · 문서 이름 · 문서 ID · 성공 여부.
